# Public edition boundaries

This repository is assembled from an explicit file allowlist. It starts with a new Git history and does not import the history of any private operating repository.

Real people and operational values were replaced with sample configuration or required local inputs. Original guest messages, bank/tax exports, completed forms, operational screenshots, staff contact lists, calendar and database identifiers, credentials and property access rules are excluded. Example addresses use `example.invalid`; example phones use the reserved 202-555-01xx range.

Do not commit a configured copy of `Config.gs`, a real identity file, operational logs or output PDFs. The shipped Apps Script projects are disabled until explicitly configured. Public code can still read personal data and change calendars when someone deliberately configures and runs it in their own account; that account’s permissions and data handling remain their responsibility.

The complete private operating repositories remain the source for operational configuration, history, detailed decisions and original evidence. Public updates are reviewed copies; they are not an automatic synchronization of private folders.
